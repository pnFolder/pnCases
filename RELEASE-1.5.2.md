# pnCases 1.5.2

Главное обновление версии — полноценная настройка кейсов через Machine. Награды, внешний вид меню, модули и основные параметры теперь можно менять через понятный GUI, не редактируя YAML вручную.

## Добавлено

- Полноценный GUI-редактор наград в Machine.
- Через GUI можно создавать награды предметами, монетами Vault, поинтами PlayerPoints, привилегиями LuckPerms, отдельными правами и командами.
- Для каждой награды можно настроить название, иконку, содержимое, шанс, редкость и положение в списке.
- Добавлена отдельная настройка отображения награды в анимации и истории. Командной награде теперь можно назначить понятное название и любой предмет или Base64-иконку.
- Добавлена AnvilGUI для удобного ввода названий, сумм, команд, привилегий, прав и других значений без ручного редактирования YAML.
- Добавлена настройка разметки меню кейса через GUI. Можно назначать слоты открытия, истории, анимации и декора, а также устанавливать собственные предметы.
- Добавлена система модулей. Через Machine или `config.yml` можно отдельно включать и отключать редкости, просмотр наград, анимацию GUI и анимацию заголовка.

## Изменено

- Настройка кейса в Machine полностью переработана и разделена на понятные категории.
- Отдельная секция `keys` удалена. Каждый созданный кейс автоматически получает собственный виртуальный ключ.
- Список наград получил новый дизайн, понятные подписи, тематические иконки и отдельное подтверждение удаления.
- Порядок наград теперь настраивается через наглядный список позиций.
- Название меню кейса теперь изменяется через AnvilGUI.
- `config.yml`, `gui.yml` и `messages.yml` очищены от устаревших и неиспользуемых настроек. Старые параметры удаляются автоматически при обновлении.
- В `gui.yml` оставлен один плейсхолдер `{rarity}`, который сразу содержит цвет, символ и название редкости.
- Справка `/pncases` стала компактнее: убраны неработающие клики, лишние сообщения обновления и технический текст.

## Исправлено

- Исправлен спам ошибки `missing required data class java.lang.Float` у анимации дракона на Paper 1.21.11. Анимация корректно передаёт данные частице `DRAGON_BREATH` и гарантированно завершает задачу.
- Исправлены плейсхолдеры редкости: цвет, символ и название теперь отображаются правильно.
- Исправлено отображение версии сервера в административной информации `/pncases`.
